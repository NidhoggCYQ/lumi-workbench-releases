# 噜咪工作台 0.7.5-beta.2（预发布测试版）

面向 Windows x64 的视频制作工作台：以 Kd 项目管理为主界面，内置画布，连接 Wan 网站 CLI、即梦 CLI及阿里云百炼 API。用户在 Codex 或其他具备本机文件、命令能力的 AI 聊天中确认需求、剧情和本批费用，再由 AI 通过支持入口执行。

可下载版本以 [GitHub Releases](https://github.com/NidhoggCYQ/lumi-workbench-releases/releases) 的实际发行记录为准。此公开程序包含现行五套剧情、三套生成配置和四份正式规范的脱敏默认模板；不含发布者的账号、API Key、任务、视频、费用明细、数据分析资料或私人工作区。

## 安装与开始

1. 获取发行页的 Windows x64 安装包。首次安装固定放在系统实际桌面的“噜咪工作台”总文件夹。
2. 双击总文件夹中的“噜咪工作台.exe”。“程序/版本”保存应用，“项目资料/工作区”保存正式配置、剧情与记录；凭证和画布本机数据另行管理。
3. 首次选择资料来源：预览采用内置五套剧情、预览接续旧 Kd 工作区，或导入同事分享的配置包。默认模板先预览再明确采用；已有内容不会被程序更新覆盖，初始化不会创建演示任务或自动生成视频。
4. 在 AI 工具中添加整个“噜咪工作台”总文件夹，复制根目录“启动对话提示词.txt”到新聊天。AI依次完整阅读 AGENTS.md、AI接手指南.md、AI制作工作流.md，再按真实ID读取当前项目的剧情、生成配置和适用规范正文。
5. 按需配置已有官方 CLI 或在画布连接设置填写自己的百炼 API Key及业务空间。各通道凭证分别管理，保存配置不代表认证、余额或模型权限已核验。

“噜咪工作台.exe”用于打开应用，“噜咪同步.exe”供 AI 后台调用。制作期间保持工作台正常打开；入口就绪、AI连接与正文已读分别核对。

## 剧情、配置与制作

- 五套共用剧情：工具替换、咕嘎捣乱、开门出现东西、大型物体追、奶茶整蛊。三条生成通道分别维护参数、素材策略和提示词要求，不复制多份剧情。
- 配置包支持逐项预览、差异审阅、同内容跳过和冲突副本；不携带 Key、登录、任务历史或原片。导入与程序升级分别处理，个人修改保留。
- 规则中心展示全文、版本、来源与作用域。制作规范需明确采用；历史授权与附件文字不构成本次付费、上传或发布授权。
- 工作流：AI读取正式配置和适用规范 → 用户确认需求、剧情 → AI准备完整提示词、自查并修正复查，完成目录预检、真实素材绑定和核价 → 在同一轮回复中交付完整提示词、具体自查/修正/复查结果及逐条与整批报价 → 用户本次明确批准 → 将本次已批的所有方向先导入统一队列 → 持续查询、下载、音画检查、封面标题与交付。批准范围内可继续的原批次由 AI 接续，不反复要求用户点击接管；新增重做、费用扩大或真实阻塞须如实说明。
- 受理不明（unknown）先查原请求和原任务，禁止改请求重付。状态可通过后台支持入口查询和接续，通常无需占用屏幕。生成成功不代替实际音画验收；审核失败、任务不可恢复等平台限制仍可能阻塞。发布账号选择、废弃和“一键更新”沿原业务流程维护。
- AI通过 `ai delivery status/numbering/cover/prepare/commit` 完成原任务的检查与正式交付，回读指定目录中的文件、标题和结果记录。已下载到应用缓存还需要继续交付；音画检查依据由实际操作者提供，软件不自动判断内容是否合格。
- 费用默认查看今天，可选单日、最近七天或日期范围，分别展示人民币、万相积分、即梦积分与免费秒数的每日趋势和逐视频记录。项目从首次启用登记的统计首日开始；旧历史不混入，凭证未核实显示待核实，报价和批准不冒充实际扣费。

画布可从项目首页新建或继续项目，也可在应用内或独立画布窗口编辑；切换编辑面与退出前会等待保存。

正式制作按日期组织画布：一天一个 `YYYY-MM-DD` 项目，五个剧情方向分别占一列，任务及结果在列内向下接续。创作中心可选择日期并打开当日画布。旧画布与已绑定历史任务继续使用原位置，不随升级自动迁移或重排；同名历史项目冲突及200张卡片容量不足会明确提示。

多个AI聊天可以分别连接同一个工作区，并按正式任务ID声明归属。不同任务可同时准备、导入及核价；同一任务由一个有效会话维护，不能串用其他聊天的报价或费用批准。工作期间按返回间隔保活，结束仅断开自己的连接。全局剧情配置等共享修改仍需协调其他会话，并核对实际版本。视频生成由统一队列调度，本机百炼批次共享硬限最多5路，下载队列独立最多2路；其余任务排队并自动接续。平台可能给出更低限额，其他电脑也共用平台主账号的限制，不能保证数十条同时在云端生成。画布最多200张卡片，按每条含参考和结果等4张卡片估算约50条标准任务，实际以当前卡片数和预检为准。

## 资料、旧项目与移动

旧 Kd 接续先预览来源、目标与缺项，再确认复制必要业务文档和记录；旧源不修改、不删除。配置包不能代替任务历史接续。旧模型稿的ID、版本和冻结历史继续保留。

视频、封面、参考图、原 Excel、归一化数据和旧缓存保持已登记原位置，不自动搬迁；缺文件如实提示。旧独立画布项目、登录、Key与 AI 聊天数据库不自动迁入。

已有成片、分析根优先复用；首次真实制作或确认分析导入时按规则准备目录，不在初始化阶段预造业务日期目录。新片首次不加发布账号。

AI草稿、报价和检查恢复材料放已绑定的外部材料根下“创作工作/日期/任务”，聊天截图及临时 JSON 放其“临时文件/日期”。无需把材料根再添加为第二个 AI 项目。已有材料不因统一入口自动迁移或清理。

保存并正常退出后可移动整个工作台总文件夹，再从新位置启动并核对定位。移动后用户需在 AI 工具中重新选择主文件夹；外部成片、分析和材料根不会随应用移动。新旧位置同时存在有效项目时须先明确选择，不能用空白目录冒充恢复。

## 费用与账号

百炼 API采用人民币本地上限预算，免费模式核对具体模型免费秒数；Wan和即梦分别使用各自官方积分，单位不能混加。网站 AccessKey与百炼 Key互不替代。API账号在用户本机配置，可切换新批次默认账号；已有批准或受理任务保留原账号身份。

费用记录区分报价、批准、本地预留、实际扣费与退款；实际费用按凭证登记。无账单证据保持待核对，不把生成失败猜成免费，不把本地预算当成云端实时余额。

## 更新与限制

更新核验来源、版本、发行签名清单、程序摘要与资料兼容性，再切换程序。个人剧情、规范、历史、通道配置和本机凭证保持；更新不自动采用新的团队配置，不自动清理旧版本或降级资料。

从早期0.5版本更新后，使用桌面“噜咪工作台”总文件夹中的新入口。原 AppData 安装程序会保留，新安装器不自动卸载旧版；新旧程序不可同时操作同一工作区。不要单独运行旧版卸载器，新旧版共用卸载登记，旧卸载器可能删除新版快捷方式或登记。不要按名称盲删旧目录或工作区，先核实其中是否仍有唯一的个人资料。

当前发行清单使用 Ed25519签名；Windows可执行文件尚无 Authenticode代码签名。两种签名分别核对。安装前保存视图，提交回执不明时先恢复原任务；关闭本机应用不会取消云端任务。

这是测试版。CLI需使用各自官方环境及本机认证；保存 Key或隔离测试不表示真实账号与生成质量通过。当前百炼适配支持文本及真实图片参考；视频、音频参考尚未接入此生成适配器。需要外部生成服务的操作遵循对应服务的权限、额度、费用和审核结果。
